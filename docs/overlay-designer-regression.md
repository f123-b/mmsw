# Overlay 设计器回归清单

本清单只验证 Overlay 的显示层、布局编辑器和鼠标命中，不启动假面试，也不改变 ASR、问题识别、回答生成、截图回答或历史记录链路。

## 未开始面试

- [ ] 打开“设置 → 悬浮窗设计器 → 编辑真实窗口”，能进入布局编辑。
- [ ] 编辑模式显示模拟问题“CAN 总线是什么？”、模拟回答和控制栏。
- [ ] 移动到全屏 Overlay 空白区域，下面的设置页或其他桌面应用仍可点击。
- [ ] 拖动问题导航、答案阅读器、控制栏，拖动离开原窗口边界后仍持续移动。
- [ ] 从上、右上、右、右下、下、左下、左、左上八个方向调整大小。
- [ ] pointerup、pointercancel、切换窗口焦点后不会留下鼠标锁；Esc 和“完成布局”都能退出。

## 面试中

- [ ] 控制栏始终可点击。
- [ ] 自动 / 手动可切换。
- [ ] 问题显示 / 隐藏可用。
- [ ] 答案显示 / 隐藏可用。
- [ ] “退出面试”可以打开原有确认框，并仍调用原有结束流程。

## 内容窗口交互模式

- [ ] `interactive`：内容窗口和控制栏可交互。
- [ ] `click_through`：内容窗口可穿透，控制栏仍可交互；临时交互键可恢复内容操作。
- [ ] `full_passthrough`：问题和答案可穿透，控制栏、退出确认框、布局工具条仍可交互。
- [ ] `Ctrl+Alt+P` 仍按原语义切换交互 / 穿透安全模式。

## 布局预设

- [ ] 紧凑：窗口较窄、面积较小。
- [ ] 标准：问题与答案合理并排。
- [ ] 宽屏：问题与答案明显更宽。
- [ ] 双屏：按当前显示器的工作区和缩放比例生成几何。
- [ ] 透明纯文字：布局切换同时使用纯文字外观，文字仍可见。
- [ ] 自定义：手动拖动、缩放或输入坐标后自动进入自定义。

## 预览编辑器

- [ ] 图层选择器可选择控制栏、问题导航、答案阅读器，未选中的对象不显示调整点。
- [ ] 50% / 75% / 100% / 125% / 适应窗口只改变预览显示，不改变设计坐标。
- [ ] “放大编辑”在应用内打开大画布，不打开第二个 Electron 窗口。
- [ ] 选中对象旁可直接编辑 X、Y、宽度、高度，并回写同一份 `OverlayPreferences`。
- [ ] 显示器列表来自 Electron `screen.getAllDisplays()`，包含工作区、尺寸和缩放比例。

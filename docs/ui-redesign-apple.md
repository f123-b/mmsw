# Interview Copilot Apple UI 重构说明

## 体验主线

用户打开应用后只需要沿着一条主线完成工作：

`工作台 → 面试准备 → 开始面试 → 悬浮回答 → 面试历史`

侧边栏保留全部能力，但按用户目标分组，而不是按内部模块分组：

- 工作台：新对话、开始面试、笔试解题
- 准备：面试准备、档案与简历、演讲稿
- 资料：项目库、资料库、通用题库、岗位要求
- 记录：面试历史

设置与帮助固定在侧边栏底部，属于低频入口。

## 页面与操作逻辑

### 工作台 / 新对话

首屏只回答三个问题：当前是否准备好、下一步做什么、最近一次对话在哪里。主按钮打开面试设置 Sheet；快捷入口分别进入档案、项目库和对话。底部 Composer 用于向 Copilot 提问，发送后进入可恢复的流式对话。

### 开始面试

页面展示本轮上下文（岗位、重点项目）和设备状态。点击主按钮打开 `InterviewSetupModal`，按“档案 → 面试方向 → 回答模式 → 音频检查”的顺序完成准备；开始后进入悬浮窗，不在页面内重复渲染复杂控制。

### 笔试解题

沿用截图触发和结构化回答流程。页面只负责选择模式、查看当前截图结果和开始 / 停止；运行中的问题、答案和快捷键仍由悬浮层承载。

### 面试准备

用户输入目标后启动准备 Agent。事件按时间线显示；遇到写入动作显示轻量审批行，允许 / 拒绝后继续。停止、失败和完成都通过底部 Toast 告知，不弹出阻断式通知卡。

### 档案与简历

档案是所有面试的个人上下文来源。左侧选择档案，右侧分为基础信息、资料关联、技能、表达偏好和自我介绍。上传或分析动作采用 Sheet / Toast 反馈，切换档案立即同步为当前活动档案。

### 项目库

项目列表与项目详情采用 macOS split view。详情内使用 Segmented Control 在概览、资料、问题、复盘间切换；危险操作放入 `…` Popover。项目 Agent 的提问范围固定为当前项目，生成后的事实和问题必须经过审核才进入可用知识。

### 资料库

资料库负责原始文件。新建、重命名和删除走系统风格确认 Sheet；上传后显示 processing 状态，完成后提供类型调整和重建索引。空状态只保留一个“导入资料”动作。

### 通用题库

默认进入题目列表，搜索、筛选和批量操作都在顶部 Toolbar 完成。选中题目后在右侧编辑面板操作；生成答案属于长任务，显示进度和可重试状态。重复题目合并放在 Popover 中，避免把维护动作长期占据主界面。

### 岗位要求

导入 JD 后先显示解析中的状态，再展示当前岗位和要求列表。岗位要求作为面试上下文被自动带入；切换岗位只改变下一场面试的快照，不修改历史记录。

### 面试历史

左侧为可搜索的面试 / 笔试记录列表，右侧为详情。详情按摘要、转写、问题、回答和导出组织；删除必须二次确认。历史记录是只读回顾，不反向修改当前档案。

### 演讲稿

上传、替换和移除都保持在当前页完成。开始面试后，演讲稿只通过悬浮控制栏显示 / 隐藏，滚轮阅读不会改变面试窗口的交互模式。

### 设置

设置分成常规、悬浮窗、技术术语、模型与 API、语音识别、检索模型、快捷键、隐私保护和关于。低频 / 高风险配置折叠在高级区；保存成功使用 Toast，连接测试和设备探测显示 inline 状态。

### 帮助

帮助页只提供快速开始、常见问题、快捷键和设置入口。遇到运行中问题时，优先引导用户回到当前任务，而不是跳转到诊断后台。

## 统一交互规则

- `⌘K / Ctrl+K` 打开 Command Palette，可用上下键选择、Enter 执行、Esc 关闭。
- 主行动只有一个蓝色按钮；次要操作使用透明或半透明灰色控件。
- Hover 使用轻微灰色材质变化；Press 使用 1px 位移；Focus 使用蓝色外轮廓。
- 成功、运行、警告和错误只显示为状态点或小标签，不使用整块彩色面板。
- 删除、重置、离开未保存编辑统一使用确认 Sheet。
- 窗口收窄时侧边栏从 250px 收到图标栏，正文保持可滚动，不使用整体缩放。
- Light Mode 为默认；Dark Mode 使用系统设置自动切换。

## 设计 Token

颜色、圆角、阴影和模糊集中在 `styles.css` 的 `--apple-*` Token 中。所有业务页复用同一套 `detail-sheet`、`settings-section-card`、`clean-list`、`clean-list-row`、`dark-pill`、`outline-pill` 和 `command-palette` 视觉语言。

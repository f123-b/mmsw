| 现象 / 样本 | 根因与本次处理 |
| --- | --- |
| 已填写自我介绍，仍由模型回答 | 旧路径同时要求“已审核”和“简历版本一致”，导致手动草稿被跳过。改为已保存的手动/上传稿优先，兼容旧草稿；简历变更只提醒，不自动停用。 |
| “FOC 项目为什么？”随后才说“选 F405 作为主控” | ASR 标点不是问题结束信号。识别开放谓语，保留等待中的问题，收到后半句后合并。 |
| “定时器是如何”＋“触发 ADC 采样”、“DMA 用的什么”＋“什么模式” | 修正不完整谓语、技术概念识别与短补语归并。准确模式适当增加稳定等待，有持续增量时不提前提交。 |
| 摩擦状态机与抗齿槽补偿被拆开 | 给这类明显并列问题更长的补充窗口；追加片段保留到同一题中。无法保证任意停顿都正确切分，因此同时增加连续问答补救。 |
| ADC 后面的 Id/Iq 问题错误继承 ADC | 明确说出的新技术实体优先；规范拼读的 Id/Iq、ABZ，不把旧主题强行加到新问题前。 |
| 已识别的问题却没有回答 | 部分被严格项目题库/证据校验拦截，不等于漏识别。保留校验，问题卡上显示具体原因与重试；避免行为问题误入项目专属硬门。 |
| 左窗停留在旧文本 | 滚动监听只依赖转写 ID，忽略同一 ID 的文本增长；滚动容器布局也可能撑开而不滚。修正布局、增量跟随、分通道事件合并，并加入显示恢复与安静期快照同步。 |

“说实话的”“川种县”等文字在没有原始音频时不能可靠还原，本次没有硬编码猜成技术名词。记录中涉及 UART 频率、个人实现和改进方案的回答，也不能仅凭流畅程度判定真实，应与项目来源逐条核对。

## 使用变化

1. **自我介绍**：档案 / 简历 → 自我介绍 → 填写后“保存并使用”。按已保存原文展示；留空并保存才恢复模型生成。AI 生成的草稿需检查后保存选用。技术/项目问题不会套用自我介绍。
2. **回答窗**：保留多条完整问答，包含排队、生成中、失败/资料不足的状态。空间不足时滚动，新问题到达跟随到最新。可以向上回看，或点“回到最新”。失败卡可“重试本题”。
3. **对话窗**：面试官在左，候选人在右；显示最近最多 160 个对话块，持续转写按内容更新。面试历史仍由原存储链路管理。左右气泡按系统音频/麦克风来源区分，并非新增声纹识别。
4. **笔试窗**：统一题目、状态、答案和分页按钮的视觉层次；截图按钮改为图标＋文字＋悬停进度。保留悬停 1 秒、移开取消、原位不重复触发、补图、重拍和焦点保护。
5. **演讲稿**：拖动标题栏移动；四边及四角缩放，位置和尺寸持久化；新增自动滚动、三档速度、字号加减、回到开头。手动滚轮会暂停自动滚动。保持非激活窗口及共享保护。
6. **项目库**：新增四步引导、资料类型说明、项目说明与问答模板，以及打开即见的匹配自测区。自测展示命中问题和已确认答案，提醒来源、单位、职责和无资料问题的核验方法。

## 项目库推荐操作与验收

- 一个项目一个空间，先选清个人、团队、部分负责或学习参考。
- 项目说明、设计说明、调试/测试记录：MD、TXT、DOCX、可提取文字的 PDF。
- 源码：ZIP，保留 README、配置和关键源码；去掉依赖、编译产物、密钥和无关内容。
- 已有问答：在“项目题库 → 上传项目题库”导入，按模板填写成对的问题和答案。空模板不能当作真实事实确认。
- 核对资料原文、参数单位、条件、个人职责后，再确认事实及问答；AI 草稿不自动视为事实。
- 在“测试项目库”分别测试原问法、同义问法、无资料问题。前两类应命中正确项目和答案；后一类应提示不足。同义问法没命中时补充相似问法。
- 开始面试时选择对应项目，再用相同问法做一次完整演练。匹配自测不调用 AI，只验证严格题库命中；不代表语音识别或最终回答准确率。

- 原生连续小窗：25 个问题先到达，再给前 24 题返回答案，最后一题返回资料不足。全部问题保留，回答对应正确，自动滚到末尾，失败原因与重试显示。

- 演讲稿：Playwright 实际拖动、右下角缩放、自动滚动、字号调整通过；打包程序还验证正常面试中可缩放、其他窗布局锁保持不变、非焦点属性、系统捕获保护标记和共享模式隐藏/恢复。
- 笔试悬停：开发版与打包版均通过。打包版约 **1005 ms** 首次触发，无点击，原位只触发一次，移开再进入重新触发；两次截图并显示本地测试答案，全程保持外部答题窗口焦点，结束后恢复主窗口。
- 界面检查使用 Playwright 技能与独立测试数据；连续回答/转写采用确定性测试事件，笔试答案由本地测试服务提供，未调用用户真实模型账号。

尚未验证：原始音频重新识别、真实模型回答内容的准确率、长时间真实双人会议、各会议软件/共享方式下的实际捕获结果。操作系统保护标记通过，不等于所有共享软件都绝对不可见。

# Interview Copilot 0.1.8

本版本修复笔试小窗拖动和面试漏答问题：

- 笔试设置为“可交互”后，可直接拖动小窗标题栏并保存位置。
- 明确完整的问句直接进入回答流程，不再因 ASR 置信度或项目指代等待第二个超时窗口。
- 隐藏“正在等待问题说完整”和“识别内容不确定，等待补充”等占位提示。
- 项目题库没有精确命中、会话没有锁定单一项目时，继续使用已上传简历、项目库、当前对话和通用技术知识回答。
- “你有什么优势”等独立个人问题不再继承上一道项目题的资料缺失状态。
- 回答仍禁止虚构个人经历、职责和指标；证据不足处使用通用技术解释补足。

回归测试覆盖 2026-09-04 面试记录中的项目介绍漏答场景、项目题库未命中后的继续作答、优势问题，以及低置信度完整问句。

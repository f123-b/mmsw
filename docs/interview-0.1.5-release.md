# Interview Copilot 0.1.5 · 上下文与稳定性修复

日期：2026-09-03；Windows x64。保留现有简历、项目、题库、历史、ASR、笔试悬停和共享保护功能。测试使用独立资料目录，没有修改用户现有数据。

## 本次修复

1. **上下文识别**：追问优先继承最近的面试官问题与最近提及实体，不再优先引用旧硬件名称或模型回答里的词。例如 DMA →“它有什么优势”仍指 DMA；明确换到 TCP/UDP 时不继承 DMA。修正“这个项目”等长指代的匹配顺序。
2. **FOC 项目依据**：原先严格模式未命中“已确认问答”便直接阻断，代码/设计类项目资料也未完整进入快速缓存。现在先使用已确认问答；没有匹配问答时，允许根据同项目关联文档、可信事实及相关简历经历生成。支持项目名称中的 FOC 缩写。多个同名/缩写项目仍须明确选择；空白项目和其他项目的资料不能充当依据。
3. **回答顺序**：按问题首次出现顺序排列回答、等待和资料不足卡片。旧问题的状态更新不会把它重新移到末尾，新问题会继续出现在底部并跟随滚动；每题保留独立重试入口。
4. **顶部控制栏**：修正左窗隐藏状态未用于原生窗口可见性的问题。针对 Windows 非激活透明窗偶尔只收到鼠标抬起、没有按下/点击事件的情况，增加受限点击补偿，并消除补偿与延迟原生点击的双触发。保持非激活和共享保护，不修改全局点击行为。提高面试控制栏最小尺寸，保留结束入口。
5. **演讲稿**：启动时恢复已上传稿件的可用状态，避免较晚返回的旧读取结果覆盖新稿件。正常面试中可通过标题拖动、边缘缩放、自动滚动；对非激活窗口的缺失按下事件，仅在专用拖动/缩放手柄恢复。
6. **退出与性能**：退出先隐藏小窗、恢复主界面，网络/音频清理并行执行，共用默认 2 秒截止时间。重复退出合并；取消启动、启动失败及关闭应用时阻止旧异步结果重新开启面试。控制栏和演讲稿不再处理完整回答存储/实时转写；避免重复设置原生置顶属性。
7. **模型接入**：增加 Chat Completions、Responses、Claude Messages 三类协议的请求、鉴权、非流式/流式解析、图像输入、错误和取消处理；连接测试采用与实际回答相同的协议。完整保留供应商 API 路径前缀。模型目录只是建议，所有任务模型 ID 可手填，刷新目录不清空手动值；供应商模板创建独立配置，不携带旧供应商密钥。

## 主流模型如何配置

| 接口/供应商 | API 协议 | Base URL 示例 |
| --- | --- | --- |
| OpenAI | Responses 或 Chat Completions | `https://api.openai.com/v1` |
| Claude 官方 | Claude Messages | `https://api.anthropic.com/v1` |
| Gemini 兼容入口 | Chat Completions | `https://generativelanguage.googleapis.com/v1beta/openai` |
| DeepSeek | Chat Completions | `https://api.deepseek.com` |
| 阿里云百炼/千问 | Chat Completions | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| Kimi、豆包、智谱、兼容网关/本地服务 | Chat Completions | 按供应商给出的完整 API 前缀填写 |

操作：设置 → 模型与 API → 选择模板/协议 → 输入模型 ID 与密钥 → 保存 → 测试连接 → 启用配置。截图解题需要在“视觉模型”填写实际支持图像的模型；没有列入模型目录时可以手填。模型目录缺项或目录接口不受支持，不代表不能手动接入。

这不是“支持所有模型的所有功能”：接入覆盖上述标准文本/图像协议；不包含每个供应商的私有工具、音频/视频接口或所有推理扩展参数。账号权限、地域地址、限流及具体模型能力仍需用该账号测试。本次没有调用用户付费账号验证每个厂商。

协议实现核对官方资料：[OpenAI Responses 流式事件](https://developers.openai.com/api/docs/guides/streaming-responses)、[迁移与请求结构](https://developers.openai.com/api/docs/guides/migrate-to-responses)、[Claude Messages](https://platform.claude.com/docs/en/api/messages/create)、[Claude 流式格式](https://platform.claude.com/docs/en/build-with-claude/streaming)、[Gemini OpenAI 兼容接口](https://ai.google.dev/gemini-api/docs/openai)。文档核对使用 OpenAI Docs 技能，界面验证使用 Playwright 技能。

## 项目库使用与测试

- 一个项目一个空间，正确关联项目说明、设计文档、关键源码或测试记录；仅在资料库上传、但没有绑定到该项目的文档，不会自动成为个人项目证据。
- 项目资料与学习参考分开；确认自己的职责、参数、测试条件后再确认事实和问答。不得把通用手册或学习参考当成实际项目结果。
- “项目题库”的匹配自测只测已确认问答匹配，不代表完整文档检索或 ASR 效果。文档回退应在面试中选择对应项目，再问“介绍一下 FOC 项目”，并对照来源核验。
- 连问“用了什么主控”“为什么选它”“它有什么优势”，检查追问对象；随后切换另一项目或技术题，检查是否正确换题。
- 没有依据时会提示补充资料并保留本题重试，而不是凭空生成。新题到来后该提示留在原位置。

# Interview Copilot 0.1.9

本版本根据 2026-09-04 真实面试记录优化项目问答：

- 每个项目新增可编辑的“项目介绍”。“介绍一下这个项目”“讲讲该项目”等概览问题直接显示已保存介绍，不调用模型。
- 项目库主入口精简为项目介绍、项目文档、项目题库和测试对话。
- 每个项目只保留两个上传入口：一份项目文档和一份项目题库。
- 新增项目回答测试对话，可在正式面试前验证项目介绍、架构问题和问题排查回答。
- 已确认项目题库和项目介绍继续走本地快速通道；未命中时保留原有项目知识检索和真实性校验。
- 八股与通用技术题按定义、原理、流程、优缺点、应用场景、常见误区和边界组织完整答案。

验证：TypeScript 类型检查通过；全量自动化测试 615/615 通过。

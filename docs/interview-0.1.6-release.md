# Interview Copilot 0.1.6 完整版

## 安装与启动

- 安装版：`Interview Copilot Setup 0.1.6.exe`。
- 免安装版：解压 `Interview Copilot-0.1.6-win.zip`，运行其中的 `Interview Copilot.exe`。
- 升级前退出正在运行的旧版，避免旧版占用全局快捷键。沿用原来的本地档案、简历、项目和设置。

## 本次修复

1. 左侧导航新增「笔试解题」，进入后点击「开始笔试」。
2. 笔试采用浅色紧凑小窗：顶部状态、中央完整答案、底部截图/新题/补图/重拍/退出。顶部可拖动，右下角可调整大小。
3. 截图按钮保持箭头，移除系统悬停提示框。悬停一秒截图，移开取消；停在原地不会重复触发。也可使用 Ctrl+Alt+S。
4. 结论、代码、步骤、公式、图表和复杂度直接连续显示，不再通过标签切换。
5. 修复「这有什么优势啊」「你的优点是什么」等完整提问被当成残句的问题。真正的半句话仍会等待后续内容。
6. 「你做过什么项目」等经历概览题使用档案中的已确认信息，不再要求先锁定一个项目。只有一个项目时，支持自动匹配泛指。涉及具体实现的回答仍依据项目资料；没有经历资料时提供填写框架，不编造个人经历。

## 语音模型配置

「设置 → 语音识别」提供 15 类模板：千问/百炼、Deepgram、OpenAI、Groq、硅基流动、OpenAI 兼容/本地 Whisper、ElevenLabs、Azure Speech、Google Cloud Speech、AssemblyAI、豆包/火山引擎、百度、腾讯云、FunASR 本地服务和自定义语音网关。

模型输入框允许填写自定义模型 ID，不受推荐列表限制。接口协议必须与服务商匹配；没有直接适配的供应商可通过自定义网关接入，需要网关实现应用的 PCM/asr_final 协议。任意厂商的任意模型并不能仅靠填写名称直接使用。

### 你使用的 qwen-audio-3.0-asr-flash

1. 供应商选「千问 / 百炼」。
2. 模型填写 `qwen-audio-3.0-asr-flash`。
3. 接口协议选「自动匹配模型」或「非实时 Flash · HTTP」。
4. 填写对应地域和业务空间的 API Key、服务地址。旧 DashScope WebSocket 地址会自动转换为 HTTP 路径；界面下方会展示实际接口。
5. 保存，然后「测试识别连接」。如果控制台给出带 Workspace ID 的地址，应完整填写该地址。

该模型走 HTTP 非实时接口，使用 format/sample_rate 参数及原生音频消息格式；程序按语音停顿分段提交。实时模型继续使用各自的 WebSocket 协议。依据：[千问 Flash 官方接口文档](https://help.aliyun.com/en/model-studio/non-real-time-speech-recognition-for-fun-asr-flash)。

供应商切换时密钥分别保存，不会把上一家密钥发送给下一家。火山旧版账号额外填写 App ID；腾讯云填写 SecretId 和 SecretKey；百度支持 API Key 或 Access Token。区域、账号权限和可用模型需与服务商控制台一致。

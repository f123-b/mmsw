# 笔试练习模式 0.1.2

本版本修复题目识别、答案结构、补图上下文、失败恢复及结果显示。未新增监控规避、隐蔽输入或点击转发功能，不能保证任何平台无法检测，也不能保证模型答案百分之百正确。

## 问题与实现

| 原问题 | 本版处理 |
| --- | --- |
| 非 JSON、截断 JSON 会被回退成“成功答案” | 严格检查对象、字段类型、题型、置信度范围、代码、图节点和表格列数；一次重新生成仍无效则报错，不保存为答案 |
| 笔试复用面试口述整理，可能改写代码和转义 | 独立笔试生成通道，不加载候选人资料、面试历史和口述改写器；缓冲完整输出后校验 |
| 损坏 Unicode 或对象强转为文本 | 拒绝替换字符、非法控制字符和孤立代理字符；保留合法中文、数学符号、表情、换行和代码反斜杠；不做二次反转义 |
| 补图只有最新一张，题目条件丢失 | 明确选择新题、补充本题、重拍本题；补图发送之前的图片及题目条件，最多 4 张；保留原约束和要求 |
| 缺图时自动生成通用占位图 | 删除自动占位图；缺少图示、完整代码、公式、表格或推导时重试一次，仍缺少则标为待核对 |
| 残缺题面也直接作答 | 模型必须报告 COMPLETE / NEEDS_INPUT；缺条件时不展示答案，显示具体补图要求 |
| 低置信度直接显示成功 | 识别或回答置信度低于 0.7 时标为待核对；置信度是模型估计，不是正确率证明 |
| 截图失败卡在忙碌状态，外层误报完成 | 截图失败同步到笔试状态；分析失败向外抛出；普通/快速模式 60 秒、深入模式 90 秒总期限；取消后阻止旧请求写入新会话 |
| 新图仍配旧答案 | 新截图开始时清除显示答案；界面依据实际处理状态显示进度、缺条件、待核对和失败 |
| 公式、表格、复杂度不展示 | 阅读器补齐相应内容；历史文本包含完整结论、代码、公式、表格、步骤和警告 |
| 截图小字经过过早缩小 | 屏幕抓取请求上限提高到 3840，再按区域裁切，输出最长边上限 2560；大 PNG 仍压缩为 JPEG，实际 MIME 随请求传递 |

## 使用

1. 退出旧版，运行本版安装程序。
2. 在设置中配置支持图片的视觉模型；三个回答模式使用视觉模型，深入模式增加思考及输出预算。
3. 启动笔试模式。主窗口和阅读器提供“下一张截图”用途选择，主窗口有“截图并分析”和“结束练习”。
4. 第一张选择“新题”。题面缺失时会自动选择“补充本题”；下一张应补上原题遗漏部分。题目已识别但要补条件时，也可以手动选择“补充本题”。
5. “重拍本题”保留历史截图，但只用新图重新识别；“新题”独立生成下一题。
6. “已通过格式检查”只表示输出结构和所需内容通过检查。仍需核对题面、计算过程和答案。代码不会自动执行，也不代表已通过编译或题库测试。

## 数据与限制

- 截图会发送到用户配置的视觉模型服务，截图及题目记录保存在本地；本版本不将这些记录加密，不承诺截图不会被第三方看到。
- 不完整、失焦或裁切的截图可能无法识别，应查看原图并重新拍摄。本版校验能拦截已知损坏字符及结构错误，不能识别所有形式的乱码或语义错误。
- 本次没有调用真实付费模型服务，验证使用固定响应、真实本地数据库和应用渲染器。因此未对真实模型在各类笔试题上的准确率作测量。
- 不自动运行生成代码；如需判断算法正确性，应在隔离练习环境用样例和边界数据测试。
